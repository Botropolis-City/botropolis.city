Botropolis

Every Claude Code session on your machine, drawn as a city.

Districts are projects, buildings are sessions, and everything on the map means one thing you can read by hovering it. A building's height is the context it has used and its beacon is its state: needs-you amber, working blue, waiting teal, unattended violet, parked slate.

It is also how you drive them. Every session becomes a background job you can close, reopen, park and wake from the map, and the terminal is only ever a view of it.

Source on GitHub

What you see

  • The power plant the API, with spend by model, project and session
  • Radio towers MCP servers
  • The library skills, ranked by use
  • Drones subagents in flight
  • Flags pull requests, green once merged
  • The storage yard parked sessions
  • The freight loop the day's tokens, one train per model

Install

Arch, from the AUR:

paru -S botropolis        # or botropolis-bin

Debian, Ubuntu, Fedora and openSUSE packages, for amd64 and arm64, are on the latest release:

sudo dpkg -i botropolis_0.1.4_amd64.deb
sudo rpm -i botropolis-0.1.4-1.x86_64.rpm

Start

systemctl --user enable --now botropolisd
botropolis install-hooks
botropolis doctor
botropolis

Then add one line to ~/.bashrc:

source /usr/share/botropolis/botropolis.bash
